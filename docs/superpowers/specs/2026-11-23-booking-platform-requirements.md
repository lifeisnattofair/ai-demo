## Ⅰ. 사업 개요

### 1. 추진 배경 및 필요성
- 한빛아트센터는 공연 예매를 외부 예매처에 맡기고, 교육 프로그램 신청은 전화와 온라인 설문(구글폼)으로 받고 있다.
- 창구가 둘로 나뉘어 회차별 정원/잔여석, 예약자 정보, 결제/환불 내역이 서로 다른 곳에 흩어져 있다. 그래서 다음 문제가 생긴다.
  - 교육 정원 초과 접수나 중복 신청을 담당자가 수작업으로 확인한다.
  - 취소/환불 기준을 창구마다 다르게 안내하고, 대기자에게 일일이 전화로 연락한다.
  - 월별 정산 때 외부 예매처 자료와 계좌 입금 내역을 손으로 대조한다.

### 2. 사업 목적
- 교육 프로그램과 기관 자체 기획공연의 예약, 결제, 취소, 환불을 하나의 회원 기반 플랫폼으로 통합한다.
- 취소 수수료, 대기 승격, 할인, 1인 한도 정책을 시스템 규칙으로 일관되게 적용한다.
- 운영 담당과 정산 담당이 같은 데이터로 회차 운영과 정산을 처리한다.

### 3. 사업 범위 (1차 사업)
| 구분 | 범위 |
|---|---|
| 대상 상품 | 기관 자체 기획공연(지정석), 교육 체험(단회차), 교육 정규 강좌(다회차, 과정 단위) |
| 사용자 기능 | 회원 가입/로그인, 프로그램 목록/상세, 회차 선택, 좌석/인원 선택, 할인 선택, 결제, 예약 확인, 취소/환불, 대기 신청/승격 결제, 알림함 |
| 관리자 기능 | 프로그램, 회차, 정원, 좌석 등급 관리, 예약 내역, 결제/환불 내역, 기관 사유 회차 취소와 일괄 환불, 정산 현황 |
| 연계 | 결제대행(프로토타입은 모의 연동, 실사업 시 결제대행사 연동), 회원 인증 |
| 데이터 | 초기 데이터 등록(가상 프로그램, 회차, 좌석) |

### 4. 단계별 추진 (향후 과제)
- **2차 사업(범위 밖)**: 대관공연 판매 이관, 외부 예매처 계약 종료에 따른 전면 전환.
- 1차 사업에서 대관공연은 기존 외부 예매처를 그대로 쓴다.

## Ⅱ. 현황 및 문제점

| 업무 | 현재 방식 | 문제점 |
|---|---|---|
| 공연 예매 | 외부 예매처 위탁 | 예매자 정보/판매 현황을 기관이 실시간으로 보지 못함, 수수료 부담 |
| 교육 신청 | 전화/온라인 설문 | 정원 관리 수작업, 중복/초과 접수, 결제는 계좌이체 확인 |
| 취소/환불 | 창구별 개별 안내 | 기준 불일치, 환불 금액 수기 계산 |
| 대기자 | 엑셀 명단 + 전화 연락 | 연락 누락, 처리 지연 |
| 정산 | 예매처 자료와 입금 내역 수기 대조 | 월말 업무 집중, 오류 가능성 |

## Ⅲ. 목표 시스템 개요

```
[사용자(회원)]  프로그램 목록 → 상세/회차 → 좌석/인원 → 할인 → 결제 → 예약 확인 → 취소/환불
                                                        ↘ (매진 시) 대기 신청 → 승격 알림 → 24시간 내 결제
[운영 담당]      프로그램, 회차, 정원, 좌석 등급 관리, 예약 내역, 회차 취소
[정산 담당]      결제, 환불 내역, 일괄 환불 승인, 정산 현황(CSV)
[연계]           결제대행 어댑터(승인, 취소, 조회, 웹훅). 프로토타입은 모의 어댑터 / 회원 인증
```

### 정책 요약 (요구사항 전반에 적용)

**취소 수수료 (공연/체험, 정규 강좌 개강 전)** - 기준일은 관람일 또는 개강일, 한국 표준시(KST) 달력 날짜 기준
| 취소 시점 | 수수료 | 환불액 |
|---|---|---|
| 기준일 8일 전까지 | 없음 | 결제액 전액 |
| D-7 ~ D-4 | 결제액의 10% | 90% |
| D-3 ~ D-1 | 결제액의 30% | 70% |
| 당일(D-0) 이후 | - | 취소 불가 |

**정규 강좌 개강 후 중도 취소** - 평생교육 시설 반환 기준을 준용. 경과 비율 = 시작된 회차 수 ÷ 총 회차 수, 「전」은 미만(정확히 1/3이면 1/2 구간). 첫 회차 시작 전에는 위 개강 전 표를 적용
| 경과 시점(총 회차 대비) | 환불액 |
|---|---|
| 1/3 경과 전 | 결제액의 2/3 |
| 1/2 경과 전 | 결제액의 1/2 |
| 1/2 경과 후 | 환불 없음 |

**기타 정책**
| 정책 | 내용 |
|---|---|
| 회원 전용 | 모든 예약은 로그인 회원만 가능 |
| 1인 한도 | 공연 회차당 4매, 체험 회차당 4명, 정규 강좌 같은 과정 본인 1건 |
| 선점 | 좌석/정원 선택 시 10분 선점, 미결제 시 자동 해제 |
| 동시 결제 | 같은 좌석/정원은 1건만 확정, 승인 직전 재검증 실패 시 결제 즉시 취소 |
| 할인 | 장애인 50%(본인 + 동반 1인), 국가유공자 50%(본인 + 동반 1인), 다자녀 30%(예약 전 매수). 매수별 1개만 적용, 중복 불가. 정규 강좌는 본인 할인만. 예약 시 유형만 선택, 증빙은 현장 확인, 미지참 시 차액 현장 결제 |
| 대기 | 매진 시 매수 지정 대기 신청 → 취소분을 순번대로 모아 1순위 수량이 차면 승격 알림(공연은 취소 좌석 그대로 배정) → 24시간 내 미결제 시 다음 순위. 기준일 D-2 이내 취소분/기한 만료는 일반 판매 전환. 정규 강좌는 개강 전까지만 대기 유지, 개강 후 추가 모집 없음 |
| 기관 사유 취소 | 회차 폐지 시 정산 담당 승인으로 해당 회차 예약 전액 일괄 환불 |

## Ⅵ. 검수(완료) 기준

| 번호 | 검수 항목 | 확인 방법 |
|---|---|---|
| AC-1 | 기본 흐름: 회원 가입 → 공연 지정석 선택 → 결제(모의 결제) → 예약 확인 → 취소, 환불액이 수수료 표와 일치 | 브라우저 검수 + 단위 테스트 |
| AC-2 | 정규 강좌 개강 후 1/3 전/1/2 전/이후 세 시점의 환불액이 기준과 일치 | 단위 테스트 + 검수용 시계 |
| AC-3 | 같은 좌석 동시 결제 시 1건만 확정, 나머지 결제는 자동 취소 | 동시 요청 통합 테스트 |
| AC-4 | 선점 10분 경과 시 자동 해제, 다른 회원이 선택 가능 | 검수용 시계 |
| AC-5 | 취소분 발생 시 대기 1순위 승격 알림, 24시간 경과 시 2순위로 이동 | 검수용 시계 |
| AC-6 | 관리자가 등록한 회차/정원이 즉시 사용자 화면에 반영, 정산 순매출 = 결제 합계 − 환불 합계 | 브라우저 검수 + 집계 대조 |
| AC-7 | 접근성 자동 점검 오류 0건, 키보드만으로 예약 완료 | 자동 점검 도구 + 수동 검수 |
| AC-8 | 모든 요구사항 ID가 구현 계획, 테스트, QA 항목 중 하나 이상과 연결 | 추적표 |
| AC-9 | 저장소에 결제 키/서비스 키 없음, 민감정보 미수집 | 비밀값 점검 + 데이터 모델 확인 |
