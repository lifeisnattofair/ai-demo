Ⅰ. 사업 개요

1. 추진 배경 및 필요성

  • 한빛아트센터는 공연 예매를 외부 예매처에 맡기고, 교육 프로그램 신청은 전화와 온라인 설문(구글폼)으로 받고 있다.
  • 창구가 둘로 나뉘어 회차별 정원/잔여석, 예약자 정보, 결제/환불 내역이 서로 다른 곳에 흩어져 있다. 그래서 다음 문제가 생긴다.
    • 교육 정원 초과 접수나 중복 신청을 담당자가 수작업으로 확인한다.
    • 취소/환불 기준을 창구마다 다르게 안내하고, 대기자에게 일일이 전화로 연락한다.
    • 월별 정산 때 외부 예매처 자료와 계좌 입금 내역을 손으로 대조한다.

2. 사업 목적

  • 교육 프로그램과 기관 자체 기획공연의 예약, 결제, 취소, 환불을 하나의 회원 기반 플랫폼으로 통합한다.
  • 취소 수수료, 대기 승격, 할인, 1인 한도 정책을 시스템 규칙으로 일관되게 적용한다.
  • 운영 담당과 정산 담당이 같은 데이터로 회차 운영과 정산을 처리한다.

구분범위

사용자 기능회원 가입/로그인, 프로그램 목록/상세, 회차 선택, 좌석/인원 선택, 할인 선택, 결제, 예약 확인, 취소/환불, 대기 신청/승격 결제, 알림함
관리자 기능프로그램, 회차, 정원, 좌석 등급 관리, 예약 내역, 결제/환불 내역, 기관 사유 회차 취소와 일괄 환불, 정산 현황

4. 단계별 추진 (향후 과제)

  • 2차 사업(범위 밖): 대관공연 판매 이관, 외부 예매처 계약 종료에 따른 전면 전환.
  • 1차 사업에서 대관공연은 기존 외부 예매처를 그대로 쓴다.

Ⅵ. 검수(완료) 기준

번호검수 항목확인 방법
AC-1기본 흐름: 회원 가입 → 공연 지정석 선택 → 결제(모의 결제) → 예약 확인 → 취소, 환불액이 수수료 표와 일치브라우저 검수 + 단위 테스트
AC-2정규 강좌 개강 후 1/3 전/1/2 전/이후 세 시점의 환불액이 기준과 일치단위 테스트 + 검수용 시계
AC-3같은 좌석 동시 결제 시 1건만 확정, 나머지 결제는 자동 취소동시 요청 통합 테스트
AC-4선점 10분 경과 시 자동 해제, 다른 회원이 선택 가능검수용 시계
AC-5취소분 발생 시 대기 1순위 승격 알림, 24시간 경과 시 2순위로 이동검수용 시계
AC-6관리자가 등록한 회차/정원이 즉시 사용자 화면에 반영, 정산 순매출 = 결제 합계 − 환불 합계브라우저 검수 + 집계 대조
AC-7접근성 자동 점검 오류 0건, 키보드만으로 예약 완료자동 점검 도구 + 수동 검수
AC-8모든 요구사항 ID가 구현 계획, 테스트, QA 항목 중 하나 이상과 연결추적표
AC-9저장소에 결제 키/서비스 키 없음, 민감정보 미수집비밀값 점검 + 데이터 모델 확인
